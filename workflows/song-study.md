# Song study workflow

## From recording to practice chart

1. **Acquire the exact version.** Start with your own recording or a download permitted by its source. Log recording/mix, source link, file format, date and allowed use. Use the same mix for every test. Streaming subscriptions commonly supply in-app playback. Use a separate audio file the tools can actually import. [Tools and audio sources](../research/tools-and-demos.md)
2. **Prepare the working audio.** Keep the original intact. If a tool needs a WAV, export a stereo PCM copy without trimming or introducing an offset. Keep the same timeline zero across all stems and charts. Name stem files by track, model and stem role. Review them solo and in context for bleed, missing attacks and artifacts.
3. **Mark time and form.** Estimate tempo, meter, beats, downbeats and section boundaries. Use Moises or All-In-One for a draft, then tap along to check half-time, double-time, pickups and tempo changes. Label repeat instances (Verse 1, Verse 2), even if chords match. Save timestamps and bar ranges, and use a tempo map for songs with variable tempo.
4. **Transcribe harmony.** Compare chord guesses from the mix against the bass and a harmonic stem. Mark each change by bar and beat, including slash bass, chord quality and any local key. Mark uncertain events. For repeated sections, compare every occurrence before collapsing their chart. Use a Roman-numeral or number version alongside a sounding chord chart. Keep bass notes and extensions when transposing, and annotate modal or borrowed chords if they affect the arrangement.
5. **Transcribe melody and lyrics.** Try Basic Pitch on an isolated melodic part and label original note names and octaves. Compare note starts, pitch bends and rhythm against the recording. For vocals, use a clean vocal stem to draft a timed transcript where authorized, then listen line by line and mark uncertainty. Store private text with start/end times, and use short cue labels in the public note where appropriate.
6. **Make alternate keys.** Choose keys by comfortable verse and chorus range, then calculate the interval from the original tonic. Shift chord roots, slash bass notes and melody pitches by that interval. Preserve chord qualities and harmonic function. Spell notes in the target key and check octave placement and singability. Document concert pitch, capo shapes and tuning separately. Keep key-shifted audio aligned to its own version if it moves time zero.
7. **Design the performance.** Give each section a subdivision, accent map, strum or comping pattern, dynamic and cue. For a genre change, choose one rhythmic trait, a voicing or texture and a change in dynamics. For an artist reference, link a specific recording and timestamp, describe the audible trait you want to try, and test it in a short take. [Worked example](../songs/porch-lights.md)
8. **Run a take.** Loop the hardest four bars, slow them down, and increase tempo only after two clean repetitions. Record a full pass with the click or backing, note the first suspect bar, then retest. Export a compact ChordPro or printed chart once the arrangement is stable. [Session template](../templates/practice-session.md)

## Comparison test

Use one 30–60 second clip you own with a clear section change and several chord changes. Write a reference chart by ear first. If you can, keep the original multitrack or MIDI as a reference. Run the same audio through Moises and Steminize, then try ChordKu or a modular tool only where the first two leave a gap.

| Measure | Capture |
| --- | --- |
| Setup and device | Version, model, OS/hardware, time to first playable result, cloud upload or local processing |
| Separation | A/B the same five seconds from vocal and guitar/keys. Mark bleed or missing phrases and identify the cleaner backing for practice. |
| Form and pulse | Count matched bar starts and section boundaries. Flag a section change if it is more than one beat off. Note any half/double-time issue. |
| Chords | On eight or more reference events, count matching root and quality. Record inversions separately and note the time or bar of each miss. |
| Key and melody | Compare two alternate keys against hand calculation and sing/play back one phrase. Record MIDI errors if using note extraction. |
| Lyrics | Compare two authorized sung phrases word by word and check line starts against playback. |
| Practice and export | Try loop and slowdown, then record whether stems, timing, MIDI and usable chart data can leave the app and be reopened. |

Choose based on the tool that supports your next practice task with the least cleanup. Keep the result with the version and clip metadata so a later retest can reproduce it.
