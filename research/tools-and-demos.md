# Tools and demos

See the [equipment checklist](equipment.md) before choosing where to run a tool. “Local” refers to audio processing. Installation, model downloads or license checks may still need a connection. Features below are documented by their developers. Device behavior, accuracy, current tiers, model licenses and third-party dependencies should be recorded during trials.

## Shortlist to compare on one recording

| Tool | Fit | What to try | Source or demo |
| --- | --- | --- | --- |
| Moises | Proprietary cloud workflow with web, desktop and mobile options. Check the feature set of the device and plan. | Import an owned file, split stems, loop a detected section, check the click, compare chord display and lyric transcription, then change key and speed. Record what can be exported. | [First session](https://moises.ai/essentials/first-session-practice-tool/) · [Chords, keys and lyrics](https://moises.ai/essentials/chords-keys-lyrics/) · [Sections](https://help.moises.ai/hc/en-us/articles/10138829000988-How-do-I-use-Sections) |
| Steminize | MIT project, pre-release. Local browser and macOS/Windows desktop builds are documented. | Test the desktop build first. Try stem separation, loop, tempo, chords and tab training. Then check whether the same file is practical in a tablet browser. | [Repository, features and demo links](https://github.com/Gerschwin/steminize) |
| ChordKu | MIT local development project. Rust/ONNX with a browser UI. | Evaluate on the workstation for synced charts, capo options, number notation, ChordPro export and transposed playback. Verify the setup, model assets and performance before adopting it. | [Project and screenshots](https://github.com/yoelkh/chordku) |
| Fadr | Proprietary browser and API option. Best candidate here to evaluate for interchange with another app. | Download stems, chord progression and MIDI from a clean example. Compare MIDI against the original. Check API availability and terms before planning integration. | [Stems walkthrough](https://fadr.com/help/stems) · [API outputs](https://fadr.com/docs/api) |

Start with Moises for the shortest path to practicing on the iPad and Steminize for the closest open-source workflow. Compare both using the [same test](../workflows/song-study.md#comparison-test) before committing to a tool or paying for a tier.

## Composable tools

| Task | Local or open-source candidates | Other tools and demos |
| --- | --- | --- |
| Find or import audio | Use your own recordings, a file you already have, or a track with a download and suitable permissions. FFmpeg normalizes copies for processing. yt-dlp is an option for permitted downloads on supported sources. | [FFmpeg](https://ffmpeg.org/ffmpeg.html) · [yt-dlp](https://github.com/yt-dlp/yt-dlp) · [Mixing Secrets multitracks](https://www.cambridge-mt.com/ms3/mtk/) · [Library FAQ](https://cambridge-mt.com/ms2/mtk-faq/) |
| Clean, trim and mark | Audacity for local waveform edits, and Sonic Visualiser for detailed listening, spectrograms, timeline annotation and analysis plug-ins. Both have desktop builds. | [Audacity](https://www.audacityteam.org/download/) · [Sonic Visualiser](https://www.sonicvisualiser.org/) · [Transcribe! desktop trial](https://www.seventhstring.com/xscribe/overview.html) |
| Separate stems | Ultimate Vocal Remover GUI on Mac/Windows, or Audio Separator for CLI/Python integration. Compare models on the real source material. The Meta Demucs upstream repo is archived. | [UVR GUI](https://github.com/Anjok07/ultimatevocalremovergui) · [Audio Separator](https://github.com/uziproj/audio-separator) · [Demucs](https://github.com/facebookresearch/demucs) · [Apple Stem Splitter requirements for iPad](https://support.apple.com/en-us/guide/logicpro-ipad/lpip1b60ada3/ipados) |
| Detect form and beat grid | All-In-One Music Structure Analyzer outputs beat/downbeat times, BPM and labeled section intervals. It is a form and timing stage. | [All-In-One visualization and browser demo](https://github.com/mir-aidj/all-in-one#visualization--sonification) · [Moises Sections](https://help.moises.ai/hc/en-us/articles/10138829000988-How-do-I-use-Sections) |
| Detect key and chords | Try Chordino in Sonic Visualiser. Essentia is an optional MIR toolkit for experimentation, with licensing to review before embedding. | [NNLS Chroma and Chordino](https://www.isophonics.net/nnls-chroma) · [Essentia licensing](https://essentia.upf.edu/licensing_information.html) · [Chordify](https://support.chordify.net/hc/en-us/articles/360002164538-How-to-use-Premium-features) · [Chord AI](https://chordai.net/) |
| Estimate notes and melody | Basic Pitch generates MIDI and works best on one instrument at a time. Try an isolated guitar or keys stem, and compare manually with the original. | [Basic Pitch repo](https://github.com/spotify/basic-pitch) · [Interactive demo](https://basicpitch.spotify.com/) |
| Draft timed lyrics | Whisper on a vocal stem is a local experiment. Review sung words and timestamps by ear, especially repeated lines, harmony and dense mixes. Keep a source note for any authorized transcript. | [Whisper](https://github.com/openai/whisper) · [Research on stem separation and lyric transcription](https://arxiv.org/abs/2506.15514) · [Moises lyric transcription](https://moises.ai/essentials/chords-keys-lyrics/) |
| Transpose and export charts | Tonal for named notes/chords and interval arithmetic. ChordPro for text interchange and formatted song sheets. Add section and bar positions to the vault note before exporting a chart. | [Tonal](https://github.com/tonaljs/tonal) · [ChordPro docs](https://www.chordpro.org/chordpro/) |
| Sing with live visual feedback | Pitchy is a browser JavaScript pitch detector. CREPE is a monophonic pitch-tracking research project to compare offline. Start with the existing app's [integration brief](../projects/vocal-training.md). | [Pitchy](https://github.com/ianprime0509/pitchy) · [CREPE](https://github.com/marl/crepe) · [Visual Pitch Trainer example](https://github.com/iuill/visual-pitch-trainer) |
| Arrange, mix and perform | GarageBand for quick Mac/iPad recording. REAPER for a shared Mac/Windows DAW workflow. SongbookPro is a candidate for ChordPro setlists on iPad, phones and Windows. MainStage is a Mac performance host. | [GarageBand for iPad](https://support.apple.com/guide/garageband-ipad/welcome/ipados) · [REAPER](https://www.reaper.fm/download.php) · [SongbookPro](https://songbook-pro.com/docs/) · [MainStage](https://www.apple.com/mainstage/) |

For source-code reuse, check the code, model weights and bundled assets independently. Record the exact upstream revision, required attribution, model download size and supported hardware before treating any pre-release project as a dependency.
